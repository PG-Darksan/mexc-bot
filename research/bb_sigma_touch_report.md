# BB20 ±σ 接触の頻度と、逆張りの利確・損切りの検証

MEXC 先物 (USDT 無期限) の 1 年分のローソク足で調べた結果。
期間は 2025-10-06〜2026-10-06 (15 分足だけ API の制限で 2025-10-11〜)。

---

## 結論

1. **4σ に触れる回数 (24h 売買代金 1M USDT 以上の時だけ数えた)**
   上側は 15 分足で年 2,742 回 (1 日 7 回ほど)、1 時間足 1,291 回 (3.4 回)、4 時間足 822 回 (2.2 回)、日足 404 回 (1 回)。
   下側もほぼ同じ数 (日足と 4 時間足は少なめ)。
2. **今の条件で入れない原因は RSI。** 4σ に触れた時の RSI(7) は中央値で 86〜89 しかなく、
   97 以上を満たすのは触れた回数の **2.5〜5.4%** だけ。
   4σ は「静かな相場からの急騰」でないと届かず、RSI 97 は「何本も続けて上げた」時に出るので、両方が同時に起きる事は少ない。
3. **RSI を外して 4σ だけで逆張りすると、ショートは負ける。**
   利確・損切りを 123 通り試して、15 分・1 時間・4 時間足で 1 年通して黒字になる組み合わせは 1 つも無かった。
   急騰は 4σ を超えてもそのまま伸びる事が多い (1 時間足だと、触れた足の中でさらに上がった幅の上位 10% が +21% 以上)。
4. **下側 (ロング) は、2025-10-10 の大暴落で結果がほぼ決まる。** この 1 日を除くと、1 時間足以上はほぼ損益ゼロ。
5. **今の決済 (EMA5 への戻りの半分で利確・損切りなし) は、勝率 80〜89% でも全部の時間足で赤字。**
   勝つと平均 +2〜18%、負けると平均 −19〜−99% (1 倍の強制決済)。
6. **緩めるなら「RSI を外す」のではなく「σ を下げて RSI を少し緩める」。**
   ショートは **3σ + RSI≥95 (1 時間足・4 時間足)** で、回数は今の 6〜7 倍、1 年の前半・後半とも黒字だった。
   利確は **接触した時の中心線 (3σ 戻した所)**、損切りは **入値から 2σ 外** (RR 1.5、勝率 45〜47%) が一番安定。
   勝率を上げたいなら損切りを 4σ に広げる (RR 0.75、勝率 60%) が、損切りの幅は % にすると中央値で 28% になる。
7. **破産しない建玉の大きさは、1 回あたり資金の 2% まで (1 倍)。** これで最大の落ち込みは 7〜14%。
   10% にすると、資金が半分になる確率が 2〜24% まで上がる。

| 出来高の条件 | **触れた時点の直近 24 時間の売買代金が 1M USDT 以上** の時だけ数える (今の時点で 1M 以上なのは 175 銘柄) |
| 時間足 | 15 分足・1 時間足・4 時間足・日足 (ボットの既定と同じ) |
| BB の計算 | ボットと同じ。進行中の足の価格を 20 本目に入れて計算し、標準偏差は母標準偏差 |
| 触れたかの判定 | 足の高値 (下側は安値) がその足の中で BB の線に届いたか。入値は線の値 (足の始めから線の外なら始値) |
| RSI | ボットと同じ RSI(7)。触れた瞬間の価格で 1 本進めた値 |
| 決済 | 利確は指値、損切りは逆指値。同じ足で両方に届いたら損切りが先 (不利な方)。入った足では利確は終値でしか判定しない。100 本で決まらなければ成行で閉じる |
| 費用 | 銘柄ごとの taker 手数料 × 2 (0 の銘柄は 0.02% とした) + 滑り往復 0.1%。資金調達料は入れていない |
| 建玉の規則 | ボットと同じく 1 銘柄 1 建玉、決済から 60 分は入らない、助走 55 本 |
| 強制決済 | 1 倍・分離マージンなので、損失は −100% で止まる (−99% で強制決済とした) |

「波」は、同じ銘柄で 5 本以内に続いた接触を 1 回とまとめた数。

**σ の意味。** BB20 の 4σ に届くには、価格が **直前 19 本の終値の平均から、その 19 本の標準偏差の 10.3 倍** 離れる必要がある
(3.5σ なら 6.0 倍、3σ なら 4.2 倍)。BB20 では 4.36σ が理論上の上限なので、4σ はほぼ上限ぎりぎりの線。

## 表の見方

### 向きと入り方 (すべて逆張り)

- **ショート** = 価格が +σ の線まで急に上がった所で売り、中心線への戻りを取る。
- **ロング** = 価格が −σ の線まで急に下がった所で買い、中心線への戻りを取る。

順張り (抜けた方向について行く) の検証は入っていない。
利確の方が損切りより大きく勝率が 5 割を切る案があるが、急騰した所から中心線までの距離が長いのでそうなる。

### 利確・損切りの「σ」

σ は触れた瞬間の BB の 1σ の幅 (価格の差)。

- 利確 3σ = 入値から 3σ 戻った所。3σ で触れた場合はちょうど中心線 (20 本の平均)。
- 損切り 2σ = 入値からさらに 2σ 行った所。

実際の取引の例 (1 時間足・3σ + RSI≥95 のショート、利確 3σ / 損切り 2σ):

```
H_USDT 2025-12-17 16:00 (RSI 95.2)。直前 3 本の終値 0.0820 → 0.0881 → 0.0915 と急騰
  損切り 0.1188  ← 入値 +2σ (+17.7%)
  入値   0.1009  ← +3σ の線に触れた所で売り
  利確   0.0741  ← 中心線 (入値 −3σ、−26.6%)
  → 5 本後に中心線まで下げて利確。費用込みで +26.4%

HMSTR_USDT 2025-12-18 08:00 (RSI 96.6)
  → 売った後も上げ続け、1 本後に入値 +2σ で損切り。−17.6%
```

### 列の意味

| 列 | 意味 |
|---|---|
| % の目安 | σ を % に直した値。その条件で触れた時の 1σ の中央値で換算したので、銘柄・時期で変わる |
| RR | 利確の幅 ÷ 損切りの幅 (3σ ÷ 2σ = 1.5) |
| 損益分岐の勝率 | 1 ÷ (1 + RR)。手数料を除けば、勝率がこれを上回ると黒字 |
| 勝率 | プラスで終わった取引の割合 |
| 1 回平均 | 1 回の取引で建玉が何 % 増減したかの平均 (手数料・滑り込み)。10 USDT で +1.3% なら 1 回 +0.13 USDT |
| PF | 勝った取引の利益の合計 ÷ 負けた取引の損失の合計。1.17 は「100 負ける間に 117 勝つ」。1 未満なら赤字、1.2 前後は薄い黒字、2 以上なら強い |
| 回数/年 | 1 年で入った回数 (1 銘柄 1 建玉・決済後 60 分は入らない、をかけた後) |
| 前半 / 後半 | 2025-10〜2026-04 と 2026-04〜2026-10 の、それぞれの 1 回平均。両方プラスなら、一時期だけたまたま勝ったわけではない |
| 黒字の月 | 13 か月のうち損益の合計がプラスだった月の数 |
| 最悪の 1 回 | 一番大きく負けた 1 回 (建玉に対する %)。損切りより大きいのは、σ が極端に大きい銘柄で損切りの幅自体が広かったか、値が飛んで損切り価格より悪く決まった時。−99% は 1 倍の強制決済 |
| 最大 DD (建玉何回分) | 損益の合計が一番高かった時から一番下がった幅を、1 回の建玉の何回分かで表したもの。1 回 10 USDT で 4.0 なら 40 USDT |

7 章の表の「1 回の建玉 (資金比)」は、入る時の資金の何 % を 1 倍で建てるか (資金 1,000 USDT で 2% なら 20 USDT)。
「1 年後の資金」は始めの資金を 1 とした倍率。
「建玉の合計」は同時に持っていた建玉の合計が一番多い時の資金比で、100% を超えると 1 倍では証拠金が足りない。

## 5. RR 比と勝率の関係

RR = 利確の幅 ÷ 損切りの幅。手数料を無視すると、損益が釣り合う勝率は **1 ÷ (1 + RR)** になる
(RR 0.5 → 67%、0.75 → 57%、1 → 50%、1.5 → 40%)。実際の勝率がこれを上回れば黒字。

読み取れる事:

- **利確が小さい (0.5〜1σ) と、勝率 80〜88% でも全部赤字。** 費用と、たまの大負けに勝てない。
- **黒字になるのは、利確が 3〜4σ (= 中心線まで戻す) の行だけ。** 3σ で触れた場合、中心線までがちょうど 3σ。
- その中で損切りを 2σ にすると RR 1.5・勝率 45%、4σ にすると RR 0.75・勝率 60%。1 回平均はどちらも +1.3〜1.7%。
- 損切りを 6σ 以上にすると、勝率は上がるが 1 回平均は落ちる。
- **利確・損切りは σ (その時の値動きの幅) で決める必要がある。** 同じ条件で % 固定にすると、
  ほぼ全部赤字だった (一番ましな「利確 20% / 損切り 30%」で 1 回平均 +0.6%)。

つまり「RR いくつなら良い」ではなく、**「利確を中心線まで取る」が先で、RR はその上で損切りの幅をどうするかの選択** になる。

## 8. ボットに入れるのに要る変更

設定だけでできる事:

- 方向ごとの σ・RSI・時間足を上の表の値にする。

コードの変更が要る事:

1. **損切りを付ける。** 今は利確しか付けていない。`order/create` の `stopLossPrice` はクライアントがすでに対応しているので、
   入る時に「入値 ± kσ」を渡せばよい。
2. **利確の基準を変える。** 今は「EMA5 への乖離 × 0.5」。これだと利確が近すぎて負ける。
   「接触した時の BB 中心線」(または入値から kσ 戻した所) にする。
3. **建玉の大きさを資金の % で決め、同時に持つ数に上限を付ける。**
4. (15 分足のショートも使うなら) 時間足ごとに σ と RSI を変えられるようにする。
5. 「行きすぎ」の入り方 (バンドから 20% 離れたら RSI を見ない) は今回検証していないので、変えるなら別に確かめる。

## 9. 注意点

- **ショートの利益は、値動きの荒い銘柄から出ている。** 1 時間足・3σ + RSI≥95 (利確 3σ / 損切り 4σ) を 1σ の幅で 3 等分すると、
  幅が小さい組は 1 回平均 −0.9%、真ん中 +1.3%、大きい組 +4.4%。15 分足と 4 時間足も同じ傾向。
  急騰したミーム系の銘柄が後で戻る分を取っている、という中身になる。
- 1 年分で、前半と後半の両方で黒字の組を選んだが、組み合わせを多く試しているので、
  実際の成績は表より悪くなると見ておく方がよい。まずは少額で動かして、表と比べるのが安全。
- 今上場している銘柄だけで調べた。上場廃止になった銘柄は入っていない。
- 資金調達料は入れていない。急騰した銘柄はショート側が払う事が多く、長く持つほど不利になる
  (ボットの資金調達のフィルタはそのまま効かせる前提)。
- 滑りは往復 0.1% としたが、急騰中の薄い銘柄ではもっと大きくなる事がある。
- 15 分足は API の制限で約 360 日分しか取れず、10/10 の暴落を含まない。
- 出来高の条件は、触れた足の終わりまでの 24 時間の売買代金で見た。4 時間足と日足では、触れた後の出来高も少し入っている。
